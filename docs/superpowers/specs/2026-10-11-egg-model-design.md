# 코스톨라니 달걀 위치 페이지 — 설계 문서

- 작성일: 2026-10-11
- 상태: 사용자 검토 대기

## 1. 목표

미국 기준금리와 물가(CPI) 데이터를 바탕으로, 앙드레 코스톨라니의 달걀 모형에서 **현재 시장이 어느 국면에 있는지**를 보여 주는 정적 웹 페이지를 만든다. 데이터는 하루에 한 번 자동으로 갱신한다.

### 성공 기준
- GitHub Pages 주소로 접속하면 달걀 그림 위에 현재 위치 점, 현재 국면 이름, 행동 설명, 주요 지표가 보인다.
- GitHub Actions가 매일 1회 FRED 데이터를 받아 `data/data.json`을 갱신하고, 페이지에 자동 반영된다.
- 국면 판정 로직이 단위 테스트로 검증된다.

### 범위 밖
- 한국 금리·한국 시장 데이터
- 사용자 입력이나 계정, 서버 측 기능
- 투자 추천 (페이지에 면책 문구를 둔다)

## 2. 구조

```
EggModel/
├─ index.html                  # 정적 페이지 (SVG 달걀 + 지표 카드)
├─ assets/app.js               # data.json을 읽어 그리기만 함 (계산 없음)
├─ assets/style.css
├─ data/data.json              # 매일 갱신되는 결과물 (저장소에 커밋)
├─ scripts/update.py           # FRED 조회 → 국면 계산 → data.json 저장
├─ scripts/phase.py            # 순수 계산 함수 (네트워크 없음, 테스트 대상)
├─ tests/test_phase.py         # pytest
├─ requirements-dev.txt        # pytest
└─ .github/workflows/daily.yml # 매일 갱신 + 커밋
```

- 계산은 Python에서 한 번만 하고, 페이지는 결과를 그리기만 한다.
- `update.py`는 Python 표준 라이브러리(`urllib`, `json`)만 사용한다. 런타임 의존성 없음.
- 프레임워크나 빌드 단계 없이 HTML/CSS/JS 파일을 그대로 배포한다.

## 3. 데이터 소스 (FRED)

| 용도 | 시리즈 | 주기 |
|---|---|---|
| 기준금리 (판정의 주축) | `FEDFUNDS` (실효 연방기금금리) | 월간 |
| 물가 (보조 신호) | `CPIAUCSL` → 전년 대비 상승률 계산 | 월간 |
| 참고 표시 | `CPILFESL` (근원 CPI) → 전년 대비 상승률 | 월간 |
| 참고 표시 | `DGS10` (10년물 국채금리) | 일간 (최신값만 사용) |

- 조회 범위: 최근 약 13년 (10년 판정 구간 + 24개월 궤적 + CPI 전년비 계산용 12개월).
- API 키는 환경 변수 `FRED_API_KEY`로 받는다. GitHub에서는 Secret으로 주입한다.
- FRED의 결측값(`"."`)은 건너뛴다.

## 4. 국면 판정 로직 (`scripts/phase.py`)

월간 기준금리 시계열 `r`과 CPI 전년비 시계열 `cpi_yoy`가 주어졌을 때, 기준월 t에 대해 다음을 계산한다.

1. **수준 L** (0~1): 최근 120개월 `r`의 최소~최대 구간에서 현재 값의 위치
   `L = (r_t − min) / (max − min)`. `max − min < 0.5%p`이면 구분이 무의미하므로 `L = 0.5`.
2. **방향 D** (−1~1): 12개월 금리 변화 `Δ = r_t − r_{t−12}`를 정규화
   `D = tanh(Δ / 1.0)`
3. **CPI 보정**: 최근 3개월 CPI 전년비 추세 `c = cpi_yoy_t − cpi_yoy_{t−3}` (%p)
   `x = clamp(D + 0.25 · tanh(c / 0.5), −1, 1)`
   물가 상승률이 오르는 중이면 금리 상승 쪽(오른쪽)으로, 내리는 중이면 금리 하락 쪽(왼쪽)으로 옮긴다. 각도로는 대략 최대 ±15°.
4. **좌표와 각도**: 가로 `x`(왼쪽 = 금리 하락기, 오른쪽 = 금리 상승기), 세로 `y = 2L − 1`(위 = 금리 고점, 아래 = 금리 저점).
   달걀 맨 위에서 출발해 사이클 진행 방향(위 → 왼쪽 → 아래 → 오른쪽 → 위)으로 잰 각도:
   `φ = atan2(−x, y)`를 도(degree)로 바꾸고 0~360으로 맞춘다.
   - 맨 위(금리 고점) = 0°, 왼쪽(하락 한가운데) = 90°, 맨 아래(저점) = 180°, 오른쪽(상승 한가운데) = 270°
5. **국면**: φ를 60° 단위로 나눈다.

| 국면 | φ 범위 | 상황 | 코스톨라니식 행동 (국내에 널리 쓰이는 해석) |
|---|---|---|---|
| A | 0–60° | 금리 고점 통과, 하락 시작 | 예금을 찾아 채권 매수 |
| B | 60–120° | 금리 하락기 | 채권 차익 실현, 부동산 매수 |
| C | 120–180° | 금리 저점 근접 | 부동산 정리, 주식 매수 |
| D | 180–240° | 금리 저점 통과, 상승 전환 | 주식 비중 축소, 현금(예금) 확보 |
| E | 240–300° | 금리 상승기 | 예금 유지, 남은 위험자산 정리 |
| F | 300–360° | 금리 고점 근접 | 예금 비중 최대, 채권 매수 준비 |

6. **궤적**: 최근 24개월 각 월에 대해 같은 계산을 반복해 `φ` 목록을 만든다.

### 함수 인터페이스
- `compute_point(rates: list[float], cpi_yoy: list[float]) -> dict` — 마지막 원소를 기준월로 보고 `{L, D, cpi_trend, x, y, angle, phase}` 반환. 데이터가 부족하면 `ValueError`.
- `compute_trail(rates, cpi_yoy, months=24) -> list[dict]`
- `yoy(series: list[float]) -> list[float]` — 12개월 전 대비 상승률(%)

## 5. `data/data.json` 형식

```json
{
  "updated_at": "2026-10-11T22:00:00Z",
  "as_of": "2026-09",
  "phase": "B",
  "angle": 97.3,
  "inputs": { "level": 0.62, "direction": -0.41, "cpi_trend": -0.12, "x": -0.43, "y": 0.24 },
  "indicators": {
    "fed_funds": { "value": 3.9, "date": "2026-09" },
    "dgs10":     { "value": 4.1, "date": "2026-10-10" },
    "cpi_yoy":   { "value": 2.8, "date": "2026-09" },
    "core_cpi_yoy": { "value": 3.0, "date": "2026-09" }
  },
  "trail": [ { "month": "2024-10", "angle": 300.2, "phase": "F" } ]
}
```
(값은 예시이다.)

- `as_of`는 기준금리와 CPI가 모두 있는 가장 최근 달이다. CPI 발표가 늦으면 두 시계열의 공통 마지막 달을 쓴다.

## 6. 화면 (`index.html`, `assets/app.js`, `assets/style.css`)

- 상단: 제목, 현재 국면(예: "B국면 · 금리 하락기"), 행동 설명 한 줄
- 중앙: SVG 달걀
  - 6개 국면 구역과 A~F 라벨, 위쪽 "금리 고점", 아래쪽 "금리 저점", 왼쪽 "하락", 오른쪽 "상승" 표시
  - 최근 24개월 궤적(흐린 선과 작은 점), 현재 위치(강조된 큰 점)
  - 점은 달걀 둘레 위, 각도 `φ` 위치에 놓는다.
- 지표 카드: 기준금리, 10년물 금리, CPI 전년비, 근원 CPI 전년비 (각각 기준일 포함)
- 판정 방법 설명 (4장 요약)과 면책 문구 ("투자 조언이 아니며 단순화한 모형입니다")
- 하단: 데이터 출처(FRED), 마지막 갱신 시각
- 한국어, 모바일 폭(좌우 16px 여백) 대응, `prefers-color-scheme`으로 라이트·다크 모드 지원
- `data.json`을 읽지 못하면 오류 메시지를 보여 준다. `updated_at`이 7일 넘게 지났으면 "데이터가 오래되었습니다" 경고를 띄운다.

## 7. 자동 갱신 (`.github/workflows/daily.yml`)

- 트리거: `schedule` cron `0 22 * * *` (UTC 22시 = 한국 시간 오전 7시) + 수동 실행(`workflow_dispatch`)
- 단계: 체크아웃 → Python 설치 → `python scripts/update.py` → `data/data.json`에 변경이 있을 때만 커밋·푸시
- 권한: `contents: write`
- GitHub Pages는 `main` 브랜치 루트에서 배포한다 (저장소 설정에서 지정).
- 조회나 계산이 실패하면 스크립트가 0이 아닌 코드로 끝나고, 커밋하지 않으므로 기존 데이터가 유지된다.

## 8. 테스트

- `tests/test_phase.py` (pytest), 합성 시계열로 검증:
  - 금리가 오르다가 고점에서 막 꺾임 → F 또는 A
  - 금리가 높은 곳에서 빠르게 하락 중 → B
  - 금리가 저점 부근에서 횡보 → C 또는 D
  - 금리가 낮은 곳에서 빠르게 상승 중 → D (y ≈ −0.6, x ≈ 0.8 → 약 233°)
  - 금리가 중간 수준에서 빠르게 상승 중 → E
  - CPI 추세가 오르면 `x`가 커지고 내리면 작아짐
  - `max − min < 0.5`이면 `L = 0.5`
  - 데이터 부족 시 `ValueError`
  - `yoy` 계산 정확성
- 수동 검증: 로컬에서 실제 FRED 키로 `update.py`를 실행해 `data.json`을 만들고, 브라우저에서 화면(라이트·다크, 모바일 폭)을 확인한다.
