**Goal:** 미국 기준금리·CPI로 코스톨라니 달걀 모형의 현재 국면을 계산하고, 매일 갱신되는 정적 페이지로 보여 준다.

**Tech Stack:** Python 3.9+ 표준 라이브러리, pytest, 바닐라 HTML/CSS/JS(빌드 없음), GitHub Actions, GitHub Pages, FRED API.

## Global Constraints

- Python 코드는 3.9에서 동작해야 한다 (로컬 3.9.0, CI 3.12). `X | None` 문법 금지, `list[float]` 같은 내장 제네릭은 허용.
- `update.py` 런타임 의존성: 표준 라이브러리만 (`urllib`, `json`). pytest는 개발용(`requirements-dev.txt`).
- FRED 시리즈: `FEDFUNDS`, `CPIAUCSL`, `CPILFESL`, `DGS10`. 결측값 `"."`는 건너뛴다.
- API 키는 환경 변수 `FRED_API_KEY`. 코드·커밋에 키를 넣지 않는다.
- 판정 상수: 수준 구간 120개월, 방향 지연 12개월, `D = tanh(Δ / 1.0)`, CPI 추세 3개월, `x = clamp(D + 0.25 · tanh(c / 0.5), −1, 1)`, `y = 2L − 1`, `max − min < 0.5`이면 `L = 0.5`, `φ = atan2(−x, y)`(도, 0~360), 60° 단위 A~F, 궤적 24개월.
- cron: `0 22 * * *` (UTC) + `workflow_dispatch`, 권한 `contents: write`.
- 페이지: 한국어, 좌우 16px 여백 모바일 대응, `prefers-color-scheme` 라이트·다크, 갱신 7일 초과 시 경고, 면책 문구, 출처 FRED 표기.
- 빌드 단계·프레임워크·외부 스크립트 없음.

## Review Focus

1. **CPI가 기준금리보다 한 달 늦게 발표됨** → `as_of`는 두 시계열의 공통 마지막 달이어야 하고, 기준금리 카드는 자기 최신 달을 따로 보여야 한다. (Task 2 `test_as_of_uses_common_last_month`)
2. **DGS10 마지막 날이 휴일이라 값이 `"."`** → 마지막 유효값과 그 날짜를 써야 한다. (Task 2 `test_dgs10_skips_missing_latest`)
3. **각도가 정확히 360°나 0° 근처** → 부동소수 오차로 360.0이 나와도 국면은 A여야 하고 `angle`은 0 이상 360 미만이어야 한다. (Task 1 `test_phase_for_angle_wraps`, `test_angle_range`)
4. **FRED 조회 실패·키 누락** → 0이 아닌 종료 코드로 끝나고 기존 `data.json`을 덮어쓰지 않아야 한다. (Task 2 `test_main_without_key_does_not_write`, `test_main_fetch_error_keeps_file`)
5. **월간 시계열 중간에 빠진 달** → 몰래 어긋난 계산을 하지 말고 `ValueError`로 멈춰야 한다. (Task 2 `test_gap_in_months_raises`)

```python
"""코스톨라니 달걀 모형의 국면 계산. 네트워크 없이 순수 함수만 둔다."""
import math

PHASES = ["A", "B", "C", "D", "E", "F"]

LEVEL_WINDOW = 120   # 수준을 잴 기간(개월)
DIRECTION_LAG = 12   # 방향을 잴 금리 변화 기간(개월)
DIRECTION_SCALE = 1.0  # tanh 정규화 기준(%p)
CPI_TREND_LAG = 3    # CPI 추세 기간(개월)
CPI_SCALE = 0.5      # CPI 추세 정규화 기준(%p)
CPI_WEIGHT = 0.25    # CPI 보정 최대 폭
MIN_RANGE = 0.5      # 이보다 좁은 금리 범위면 수준을 0.5로 본다(%p)


def yoy(series):
    """12개월 전 대비 상승률(%). 결과 길이는 len(series) - 12."""
    return [(series[i] / series[i - 12] - 1) * 100 for i in range(12, len(series))]


def phase_for_angle(angle):
    return PHASES[int(angle // 60) % 6]


def compute_point(rates, cpi_yoy):
    """rates, cpi_yoy의 마지막 원소(같은 달)를 기준으로 달걀 위 위치를 계산한다."""
    if len(rates) < DIRECTION_LAG + 1:
        raise ValueError(f"기준금리 데이터가 부족합니다: {len(rates)}개월")
    if len(cpi_yoy) < CPI_TREND_LAG + 1:
        raise ValueError(f"CPI 데이터가 부족합니다: {len(cpi_yoy)}개월")

    current = rates[-1]
    window = rates[-LEVEL_WINDOW:]
    low, high = min(window), max(window)
    level = 0.5 if high - low < MIN_RANGE else (current - low) / (high - low)

    direction = math.tanh((current - rates[-1 - DIRECTION_LAG]) / DIRECTION_SCALE)
    cpi_trend = cpi_yoy[-1] - cpi_yoy[-1 - CPI_TREND_LAG]
    x = max(-1.0, min(1.0, direction + CPI_WEIGHT * math.tanh(cpi_trend / CPI_SCALE)))
    y = 2 * level - 1

    angle = math.degrees(math.atan2(-x, y)) % 360.0
    if angle >= 360.0:  # 아주 작은 음수가 360.0으로 반올림되는 경우
        angle = 0.0

    return {
        "level": level,
        "direction": direction,
        "cpi_trend": cpi_trend,
        "x": x,
        "y": y,
        "angle": angle,
        "phase": phase_for_angle(angle),
    }


def compute_trail(rates, cpi_yoy, months=24):
    """최근 months개월의 위치 목록. 오래된 달부터, 마지막이 현재 달."""
    trail = []
    for back in range(months - 1, -1, -1):
        end_r = len(rates) - back
        end_c = len(cpi_yoy) - back
        trail.append(compute_point(rates[:end_r], cpi_yoy[:end_c]))
    return trail
```

```python
def monthly(first_year, last_month, value_fn):
    """first_year-01부터 last_month("YYYY-MM")까지 월초 날짜 관측값 목록."""
    out, y, m, i = [], first_year, 1, 0

        m += 1
```

```python
"""FRED에서 금리·물가를 받아 달걀 모형 위치를 계산하고 data/data.json에 저장한다.

사용법: FRED_API_KEY=... python scripts/update.py
"""
import json
import os
import sys
import urllib.parse
import urllib.request
from datetime import date, datetime, timezone
from pathlib import Path

from phase import compute_point, compute_trail, yoy

FRED_URL = "https://api.stlouisfed.org/fred/series/observations"
OUT_PATH = Path(__file__).resolve().parent.parent / "data" / "data.json"
HISTORY_YEARS = 13
TRAIL_MONTHS = 24


def fetch_series(series_id, api_key, start):
    query = urllib.parse.urlencode({
        "series_id": series_id,
        "api_key": api_key,
        "file_type": "json",
        "observation_start": start,
    })
    with urllib.request.urlopen(f"{FRED_URL}?{query}", timeout=30) as resp:
        return parse_observations(json.load(resp))


def parse_observations(payload):
    return [
        (o["date"], float(o["value"]))
        for o in payload["observations"]
        if o["value"] not in (".", "")
    ]


def to_monthly(obs):
    return {d[:7]: v for d, v in obs}


def _month_index(month):
    return int(month[:4]) * 12 + int(month[5:7]) - 1


def _year_before(month):
    return f"{int(month[:4]) - 1:04d}{month[4:]}"


def _check_contiguous(months):
    for a, b in zip(months, months[1:]):
        if _month_index(b) - _month_index(a) != 1:
            raise ValueError(f"월간 데이터에 빠진 달이 있습니다: {a} → {b}")


def _latest_yoy(monthly):
    month = max(monthly)
    return month, (monthly[month] / monthly[_year_before(month)] - 1) * 100


def build_payload(fed, cpi, core, dgs10, now):
    fed_m, cpi_m, core_m = to_monthly(fed), to_monthly(cpi), to_monthly(core)

    months = sorted(set(fed_m) & set(cpi_m))
    _check_contiguous(months)
    cpi_yoy = yoy([cpi_m[m] for m in months])
    months = months[12:]
    rates = [fed_m[m] for m in months]

    point = compute_point(rates, cpi_yoy)
    trail = compute_trail(rates, cpi_yoy, TRAIL_MONTHS)
    fed_month = max(fed_m)
    core_month, core_yoy = _latest_yoy(core_m)
    dgs10_date, dgs10_value = dgs10[-1]

    return {
        "updated_at": now.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ"),
        "as_of": months[-1],
        "phase": point["phase"],
        "angle": round(point["angle"], 1),
        "inputs": {
            "level": round(point["level"], 3),
            "direction": round(point["direction"], 3),
            "cpi_trend": round(point["cpi_trend"], 3),
            "x": round(point["x"], 3),
            "y": round(point["y"], 3),
        },
        "indicators": {
            "fed_funds": {"value": round(fed_m[fed_month], 2), "date": fed_month},
            "dgs10": {"value": round(dgs10_value, 2), "date": dgs10_date},
            "cpi_yoy": {"value": round(cpi_yoy[-1], 2), "date": months[-1]},
            "core_cpi_yoy": {"value": round(core_yoy, 2), "date": core_month},
        },
        "trail": [
            {"month": m, "angle": round(p["angle"], 1), "phase": p["phase"]}
            for m, p in zip(months[-TRAIL_MONTHS:], trail)
        ],
    }


def main(fetch=fetch_series, out_path=OUT_PATH):
    api_key = os.environ.get("FRED_API_KEY")
    if not api_key:
        print("FRED_API_KEY 환경 변수가 없습니다.", file=sys.stderr)
        return 1

    today = date.today()
    start = date(today.year - HISTORY_YEARS, 1, 1).isoformat()
    try:
        series = {sid: fetch(sid, api_key, start)
                  for sid in ("FEDFUNDS", "CPIAUCSL", "CPILFESL", "DGS10")}
        payload = build_payload(series["FEDFUNDS"], series["CPIAUCSL"],
                                series["CPILFESL"], series["DGS10"],
                                now=datetime.now(timezone.utc))
    except Exception as exc:  # 실패하면 기존 data.json을 그대로 둔다
        print(f"갱신 실패: {exc}", file=sys.stderr)
        return 1

    out_path = Path(out_path)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    tmp = out_path.with_suffix(".tmp")
    tmp.write_text(json.dumps(payload, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
    tmp.replace(out_path)
    print(f"{payload['as_of']} 기준 {payload['phase']}국면 ({payload['angle']}°) → {out_path}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```js
const PHASES = {
  A: { name: "금리 고점 통과", action: "예금을 찾아 채권을 사는 시기" },
  B: { name: "금리 하락기", action: "채권 차익을 실현하고 부동산으로 옮기는 시기" },
  C: { name: "금리 저점 근접", action: "부동산을 정리하고 주식을 사는 시기" },
  D: { name: "금리 상승 전환", action: "주식 비중을 줄이고 현금(예금)을 확보하는 시기" },
  E: { name: "금리 상승기", action: "예금을 유지하며 남은 위험자산을 정리하는 시기" },
  F: { name: "금리 고점 근접", action: "예금 비중을 최대로 두고 채권 매수를 준비하는 시기" },
};
const ORDER = ["A", "B", "C", "D", "E", "F"];
const STALE_MS = 7 * 24 * 60 * 60 * 1000;
const SVG_NS = "http://www.w3.org/2000/svg";
const CX = 200, CY = 235, RX = 140, RY = 175;

// 맨 위(금리 고점)에서 시작해 왼쪽 → 아래 → 오른쪽으로 도는 각도(도)를 달걀 둘레 좌표로 바꾼다.
// 위쪽이 좁은 달걀 모양이 되도록 가로 폭을 cos에 따라 줄인다.
function eggPoint(deg, scale = 1) {
  const t = (deg * Math.PI) / 180;
  const width = RX * (1 - 0.12 * Math.cos(t));
  return [CX - width * Math.sin(t) * scale, CY - RY * Math.cos(t) * scale];
}

function el(name, attrs = {}, text) {
  const node = document.createElementNS(SVG_NS, name);
  for (const [k, v] of Object.entries(attrs)) node.setAttribute(k, v);
  if (text !== undefined) node.textContent = text;
  return node;
}

function arcPath(from, to) {
  const pts = [];
  for (let d = from; d <= to; d += 2) pts.push(eggPoint(d));
  return `M${CX},${CY} L` + pts.map((p) => p.map((n) => n.toFixed(1)).join(",")).join(" L") + " Z";
}

function drawEgg(svg, data) {
  svg.replaceChildren();
  ORDER.forEach((key, i) => {
    const cls = ["sector", i % 2 ? "alt" : "", key === data.phase ? "current" : ""].join(" ").trim();
    svg.append(el("path", { d: arcPath(i * 60, i * 60 + 60), class: cls }));
  });
  const outline = [];
  for (let d = 0; d <= 360; d += 2) outline.push(eggPoint(d));
  svg.append(el("path", { d: "M" + outline.map((p) => p.map((n) => n.toFixed(1)).join(",")).join(" L") + " Z", class: "outline" }));

  ORDER.forEach((key, i) => {
    const [x, y] = eggPoint(i * 60 + 30, 0.62);
    svg.append(el("text", { x, y, class: "phase-label" + (key === data.phase ? " current" : "") }, key));
  });

  svg.append(el("text", { x: CX, y: 34, class: "axis-label" }, "금리 고점"));
  svg.append(el("text", { x: CX, y: 446, class: "axis-label" }, "금리 저점"));
  svg.append(el("text", { x: 18, y: CY + 5, class: "axis-label" }, "← 하락기"));
  svg.append(el("text", { x: 382, y: CY + 5, class: "axis-label" }, "상승기 →"));

  const trail = data.trail.slice(0, -1);
  trail.forEach((p, i) => {
    const [x, y] = eggPoint(p.angle);
    svg.append(el("circle", { cx: x, cy: y, r: 4, class: "trail", opacity: (0.15 + (0.5 * i) / Math.max(trail.length, 1)).toFixed(2) }));
  });
  const [nx, ny] = eggPoint(data.angle);
  svg.append(el("circle", { cx: nx, cy: ny, r: 10, class: "now" }));
}

function card(label, indicator, unit) {
  const div = document.createElement("div");
  div.className = "card";
  div.innerHTML = `<p class="label"></p><p class="value"></p><p class="date"></p>`;
  div.querySelector(".label").textContent = label;
  div.querySelector(".value").textContent = `${indicator.value.toFixed(2)}${unit}`;
  div.querySelector(".date").textContent = `기준 ${indicator.date}`;
  return div;
}

function showNotice(text) {
  const n = document.getElementById("notice");
  n.textContent = text;
  n.hidden = false;
}

function render(data) {
  const meta = PHASES[data.phase];
  const title = document.getElementById("phase-title");
  title.innerHTML = `<span class="badge"></span> · `;
  title.querySelector(".badge").textContent = `${data.phase}국면`;
  title.append(meta.name);
  document.getElementById("phase-action").textContent = `${data.as_of} 기준 · ${meta.action}`;
  document.getElementById("egg-desc").textContent =
    `현재 ${data.phase}국면(${meta.name}), 달걀 맨 위에서 ${data.angle.toFixed(0)}° 지점`;

  drawEgg(document.getElementById("egg"), data);

  const ind = data.indicators;
  document.getElementById("cards").replaceChildren(
    card("기준금리 (실효 FFR)", ind.fed_funds, "%"),
    card("미 국채 10년물", ind.dgs10, "%"),
    card("CPI 상승률 (전년비)", ind.cpi_yoy, "%"),
    card("근원 CPI (전년비)", ind.core_cpi_yoy, "%"),
  );

  const updated = new Date(data.updated_at);
  document.getElementById("updated").textContent = updated.toLocaleString("ko-KR");
  if (data.sample) showNotice("예시 데이터입니다. 첫 자동 갱신 후 실제 값으로 바뀝니다.");
  else if (Date.now() - updated.getTime() > STALE_MS) showNotice("데이터가 오래되었습니다. 자동 갱신이 멈췄는지 확인해 주세요.");
}

fetch("data/data.json", { cache: "no-cache" })
  .then((r) => {
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    return r.json();
  })
  .then(render)
  .catch((err) => {
    document.getElementById("phase-title").textContent = "데이터를 불러오지 못했습니다";
    showNotice(String(err));
  });
```

```markdown
미국 기준금리(FEDFUNDS)와 CPI로 코스톨라니 달걀 모형의 현재 국면을 계산해 보여 주는 정적 페이지입니다.
GitHub Actions가 매일 한국 시간 오전 7시에 FRED 데이터를 받아 `data/data.json`을 갱신합니다.

## 처음 설정
1. https://fred.stlouisfed.org/docs/api/api_key.html 에서 무료 API 키를 발급받습니다.
2. 저장소 Settings → Secrets and variables → Actions → New repository secret: 이름 `FRED_API_KEY`.
3. Settings → Pages → Source: Deploy from a branch, Branch `main` / `/ (root)`.
4. Actions → Daily data update → Run workflow 로 첫 갱신을 실행합니다.

## 로컬 실행
    python -m pip install -r requirements-dev.txt
    python -m pytest -q
    FRED_API_KEY=발급받은키 python scripts/update.py
    python -m http.server 8000   # http://localhost:8000

## 판정 방법
```
